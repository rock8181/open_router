① 파일 탐색기에서 D 드라이브처럼 넉넉한 곳에 영어 이름 폴더(저는 city-timelapse)를 만들고, Claude 앱 Code 탭 → 새 세션 → 그 폴더 고르기 → '작업 공간 신뢰' → 아래쪽 권한을 '수동'으로
② 이 컴퓨터에 Node.js, Python, ffmpeg가 있는지 확인하고, 없는 건 설치해 줘.
③ 리모션과 three.js로 3D 영상을 만드는 프로젝트를 이 폴더에 만들어 줘. 다 되면 빈 장면을 정지 화면 한 장으로 보여 줘.
④ 오픈스트리트맵에서 서울시청 반경 2km 안의 건물을 받아 줘. 모양, 높이나 층수, 지은 해가 있으면 같이.
⑤ 건물마다 바닥 모양을 높이만큼 세워서 3D 도시를 만들어 줘. 지은 해가 되면 땅에서 솟아오르게 하고, 높이나 지은 해가 없는 건물은 주변 건물로 추정해 줘.
   → 유명 건물 연도를 바로잡을지 물으면: 주요 건물만 보정
⑥ 1970년에 삼일빌딩이 올라갈 때 이름표를 띄워 줘. 큰 건물이 올라갈 땐 연도가 잠깐 멈추게.
⑦ 먼저 정지 화면 여섯 장만 뽑아서 보여 줘.
   → 화면 글자는 모두 한국어로 바꾸고, 멈추는 건물에도 이름표를 달아 줘.
   → 좋아, 이제 15초 영상으로 만들어 줘.
＋ (선택) 리모션 공식 스킬: npx skills add remotion-dev/skills
＋ 더 고급스럽게: 화면 밝기, 그림자 색, 카메라가 멈춰 있는 비율을 숫자로 재 줘. 장면의 절반 넘게는 카메라를 거의 멈춰 둬.
