# OpenRouter 서비스 순위 분석 (이미지 기반)

OpenRouter에 등록된 서비스/모델 상위 5위를 이미지에서 확인하고 각 항목에 대해 팀 에이전트 관점에서 분석했다.

## 이미지 내용 (상위 5위)

| 순위 | 서비스명 | 링크/식별자 | 태그 |
|:--:|----------|-------------|------|
| 1위 | Claude-Mem | cmem.ai | 0일 |
| 2위 | FreeLLAMAPI | github.com/tashfeenahmed/freellmapi | 0일 |
| 3위 | Claude Code Setup | claude.com/marketplace | 0일 |
| 4위 | Elephant-Goldfish Model | egm.dev | 0일 |
| 5위 | 21st.dev MCP | 21st.dev/mcp | 0일 |

전체 항목이 "0일" 태그로 표시되어 있어, 모두 최근에 등록되거나 트렌드에 오른 신규/인기 서비스로 보인다.

---

## 팀 에이전트별 분석

### 1️⃣ Claude-Mem (1위) — cmem.ai

**제품팀 관점:**
- 메모리(Long-term Memory) 기능을 강조하는 Claude 전용 서비스로 보임. "Mem"은 메모리/기억을 뜻하며, 대화 맥락을 지속적으로 유지하려는 사용자 니즈를 공략.
- 1위 랭크는 Claude 사용자 중 맥락 기억이 필요한 유저(코딩 보조, 장기 프로젝트, 연구 보조)가 많음을 시사.

**개발팀 관점:**
- 클로드 API 연동 메모리 레이어 구현이 핵심. 벡터 DB, 스레드별 컨텍스트 저장/호출, 토큰 절약을 위한 요약 전략이 필요.
- OpenRouter 등록 시 표준 API 인터페이스 준수 여부와 레이트리밋 처리 설계가 중요.

**마케팅팀 관점:**
- "Claude" 브랜드 네임 노출로 클로드 유저 유입이 유리하나, 상표권 이슈 가능성 확인 필요.
- 0일 태그는 신규 서비스이므로 조기 adopter 확보가 관건.

---

### 2️⃣ FreeLLAMAPI (2위) — github.com/tashfeenahmed/freellmapi

**제품팀 관점:**
- 무료(Free) LLM API를 지향. GitHub 링크로 오픈소스/커뮤니티 프로젝트 성격이 강함.
- 비용 민감한 개발자, 학생, 스타트업을 타겟.

**개발팀 관점:**
- GitHub 저장소 기반이므로 커뮤니티 기여 모델. 자가 호스팅 또는 퍼블릭 엔드포인트 제공 방식 확인이 필요.
- 무료 서비스 특성상 안정성, 가동률, 레이트리밋이 상용 서비스보다 낮을 가능성이 높음. 프로덕션 도입 시 리스크 검토 필요.

**운영팀 관점:**
- 무료 API는 갑작스러운 서비스 중단 또는 유료 전환 리스크가 있음. 백업 엔드포인트 다변화 권장.

---

### 3️⃣ Claude Code Setup (3위) — claude.com/marketplace

**제품팀 관점:**
- Anthropic 공식 클로드 마켓플레이스에 등록된 "설치/설정" 관련 서비스. 클로드 코드(CLI/에이전트) 환경을 쉽게 세팅해주는 도구로 보임.
- 공식 마켓플레이스 등록은 신뢰도가 높고, 클로드 생태계 내 유저에게 직접 노출되는 이점이 있음.

**개발팀 관점:**
- claude.com 도메인은 Anthropic 공식 도메인이므로, 마켓플레이스 연동 공식 API/인증 방식을 따를 가능성이 높음.
- 에이전트 세팅 자동화, 설정 파일 템플릿 제공, IDE 연동(예: VS Code 확장)과 같은 기능이 핵심.

**마케팅팀 관점:**
- 공식 채널 등록으로 검색 노출과 신뢰 확보가 용이. 클로드 코드 유저를 직접 타겟팅할 수 있음.

---

### 4️⃣ Elephant-Goldfish Model (4위) — egm.dev

**제품팀 관점:**
- "Elephant"(코끼리, 대용량 메모리)과 "Goldfish"(금붕어, 단기 기억)의 대조적 이름이 인상적. 대규모 컨텍스트 윈도우와 단기 메모리 기능을 결합한 모델로 추정.
- egm.dev는 전용 도메인을 보유한 독립 서비스.

**개발팀 관점:**
- 모델 아키텍처가 장기 기억과 단기 기억을 어떻게 분리/통합하는지가 핵심 차별점. 컨텍스트 윈도우 크기, 추론 속도, 비용 구조 확인이 필요.
- 전용 도메인 운영이므로 API 엔드포인트 안정성과 문서화 수준을 검토.

**데이터팀 관점:**
- 모델명 메타포가 메모리 기능을 강조하므로, 실제 벤치마크(needle-in-haystack 등) 결과와 장기 의존성 작업 성능 검증이 필요.

---

### 5️⃣ 21st.dev MCP (5위) — 21st.dev/mcp

**제품팀 관점:**
- MCP(Model Context Protocol) 서버를 제공하는 서비스. 21st.dev는 UI 컴포넌트/디자인 시스템 플랫폼으로 알려졌으며, MCP 서버를 통해 AI 에이전트가 디자인/컴포넌트 자원에 접근할 수 있도록 하는 브리지 역할로 보임.
- AI 에이전트와 디자인 도구의 연동이 핵심 가치.

**개발팀 관점:**
- MCP 프로토콜(stdio 또는 HTTP 기반 서버) 구현이 필수. 클로드 데스크톱, 커서(Cursor), 윈사이드(Windsurf) 등 MCP 클라이언트 호환성 검토 필요.
- 디자인 토큰, 컴포넌트 라이브러리, Figma 연동 등의 데이터를 MCP 리소스/도구로 노출하는 방식 설계.

**파트너십팀 관점:**
- 21st.dev 기존 사용자(디자이너, 프론트엔드 개발자)를 AI 에이전트 유저로 확장할 수 있는 교차판매 기회.

---

## 종합 요약 및 시사점

1. **모두 0일 태그** → 최근 트렌드/신규 등록 서비스들로, 조기 분석과 모니터링이 필요함.
2. **클로드 생태계 집중** → Claude-Mem, Claude Code Setup 등 클로드 연동 서비스가 상위에 다수 포진. 클로드 사용자 기반 공략이 유효.
3. **메모리/컨텍스트가 키워드** → Claude-Mem(메모리), Elephant-Goldfish(장단기 기억) 등 컨텍스트 관리 서비스가 눈에 띔.
4. **MCP 부상** → 21st.dev MCP처럼 AI 에이전트와 외부 도구를 잇는 MCP 서버 서비스가 순위에 진입. 에이전트 생태계 확장 추세.
5. **무료 vs 공식 채널 양분** → FreeLLAMAPI(무료/오픈소스)와 Claude Code Setup(공식 마켓플레이스)처럼 비용 모델과 채널이 상이함. 사용자 세그먼트에 따른 접근 필요.

다음 단계로 각 서비스에 대한 직접 API 호출 테스트, 문서화 수준 조사, 경쟁 서비스와의 차별 포인트 심층 분석을 제안한다.
