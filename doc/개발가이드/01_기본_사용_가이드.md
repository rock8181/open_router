## 4. GitHub 원격 저장소 연결 및 푸시

### 4.1 원격 저장소 추가
```powershell
git remote add origin https://github.com/rock8181/open_router.git
```

### 4.2 브랜치 이름 통일
```powershell
git branch -M main
```

### 4.3 원격 저장소가 이미 존재할 경우 (pull 후 merge)
```powershell
git pull --allow-unrelated-histories origin main
```

### 4.4 푸시
```powershell
git push -u origin main
```

성공 시 출력 예시:
```
To https://github.com/rock8181/open_router.git
   d56b5c1..33ed827  main -> main
branch 'main' set up to track 'origin/main'.
```

### 4.5 푸시 후 확인
```powershell
git remote -v
git status
```

출력 예시:
```
origin	https://github.com/rock8181/open_router.git (fetch)
origin	https://github.com/rock8181/open_router.git (push)
Your branch is up to date with 'origin/main'.
nothing to commit, working tree clean
```

## 5. 문제 해결 (발생했던 이슈 및 해결 방법)

### 5.1 인덱스 락 파일 오류
```
fatal: Unable to create '.git/index.lock': File exists.
```
**원인**: 이전 git 프로세스가 종료되지 않아 `.git/index.lock` 파일이 남아있음.

**해결**:
```powershell
Remove-Item -LiteralPath ".git\index.lock" -Force
```
또는 cmd에서:
```powershell
cmd /c del /f /q ".git\index.lock"
```

### 5.2 GitHub Push Protection (시크릿 차단)
```
remote: error: GH013: Repository rule violations found for refs/heads/main.
remote: - GITHUB PUSH PROTECTION
remote: - Push cannot contain secrets
```
**원인**: 커밋에 API 키(OpenRouter 키, Gemini 키 등)가 포함됨.

**해결**:
1. 해당 파일에서 실제 키 값을 `[REDACTED]`로 마스킹.
2. `git add -A` 후 `git commit --amend`로 커밋 수정.
3. 다시 `git push -u origin main` 실행.

마스킹된 파일 예시:
- `open_router/doc/01_apikey.md`: `sk-or-v1-[REDACTED]`
- `open_router/doc/02_aistudiokey.md`: `AQ.[REDACTED]`
- `study/01_skill_claude/01_분석_claude-mem.md`: `"CLAUDE_MEM_OPENROUTER_API_KEY": "sk-or-v1-[REDACTED]"`

### 5.3 토큰 인증 오류 (403)
```
remote: Permission to rock8181/open_router.git denied to rock8181.
```
**원인**: 원격 URL에 토큰이 잘못 포함되거나 토큰 권한 부족.

**해결**: 토큰을 URL에 포함하지 않고 표준 URL(`https://github.com/rock8181/open_router.git`)로 푸시. GitHub 웹 UI에서 인증 토큰을 설정하거나 credential helper 사용.
