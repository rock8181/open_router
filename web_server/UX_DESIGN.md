## 0. 개요

본 문서는 OpenRouter 문서 뷰어의 UX 설계 사양을 정의한다. 기존 `public/style.css`의 `.gf-front`에 `opacity: 0`이 기본 설정되어 닫힌 카드에서 파일/폴더 이름이 표시되지 않는 치명적 버그를 수정하고, 사용자가 문서 폴더 계층을 직관적으로 탐색하며 카드 상태와 상호작용을 일관되게 경험할 수 있도록 설계한다.

### 0.1 문제 현황

닫힌 문서 카드의 `.gf-front`(파일/폴더명, 메타, 아이콘 포함)가 `opacity: 0` 상태로 렌더링되어 사용자가 카드 내용을 확인할 수 없다. `.gf-back`은 비어 있어 카드 뒤집어도 내용이 표시되지 않는다. 이는 "닫힌 카드에서도 이름과 메타를 보여줘야 한다"는 카드 상태 사양에 위배된다.

### 0.2 설계 원칙

1. **내용 우선**: 닫힌 카드에서도 이름, 메타, 아이콘을 항상 가시적으로 표시한다.
2. **상태 명확성**: Closed/Open/Hover/Selected 네 상태를 시각적으로 구분한다.
3. **키보드 우선**: 모든 기능은 마우스 없이 키보드만으로 조작 가능하다.
4. **접근성**: WCAG AA 대비 4.5:1, 포커스 링, ARIA, 터치 대상 44×44px 준수.
5. **디자인 시스템 준수**: `DESIGN_SYSTEM.md`의 색상/타이포그래피/간격/반경/그림자 토큰을 따른다.

## 1. 정보 아키텍처 (Information Architecture)

### 1.1 폴더 → 문서 계층

```
루트 (Root)
├── 폴더 (Folder)
│   ├── 하위 폴더 (Subfolder)
│   │   └── 문서 (Document, .md / .txt)
│   └── 문서 (Document)
└── 문서 (Document, 루트 직접 배치)
```

- 최상위는 `root` 파라미터(`open_router`, `study` 등)로 구분한다.
- 폴더는 클릭 시 해당 폴더 내부의 문서/하위 폴더 목록 뷰로 이동한다.
- 문서는 클릭 시 뷰어 오버레이에서 내용이 렌더링된다.
- 검색 결과는 계층과 무관하게 플랫한 결과 목록으로 표시되며, 결과 항목에 `[root] 경로` 메타를 붙여 맥락을 제공한다.

### 1.2 브레드crumb 경로

```
open_router > doc > study > 01_skill_claude
[홈] [open_router] [doc] [study] [01_skill_claude (현재)]
```

- 현재 경로를 좌→우로 표시한다.
- 모든 세그먼트는 클릭 가능하며, 클릭 시 해당 경로로 이동한다.
- 마지막 세그먼트는 현재 위치를 나타내며 링크가 아니다(`aria-current="page"`).
- 검색 모드에서는 "검색 결과" 텍스트만 표시되며 클릭不可.
- 모바일에서는 overflow 시 끝 세그먼트를 우선 표시하고 가로 스크롤을 지원한다.

### 1.3 검색 범위 (Search Scope)

| 범위 | 설명 |
|------|------|
| 전체 검색 | 모든 루트/폴더의 문서 인덱스에서 키워드 검색 |
| 현재 폴더 한정 | 표시 중인 폴더 내 문서만 검색 대상 |
| 즐겨찾기 한정 | 별표 표시 문서만 검색 대상 |
| 태그 한정 | 선택된 태그가 붙은 문서만 검색 대상 |

- 검색 입력은 페이지 상단 고정, 자동 포커스.
- 결과는 문서명, 일치 스니펫, 경로, 루트 태그를 함께 표시.
- 검색어는 결과 및 뷰어에서 하이라이팅된다.

## 2. 카드 상태 (Card States)

모든 문서/폴더 카드는 아래 네 가지 상태를 갖는다. `aria-expanded`로 열린/닫힌 상태를 노출하고, 키보드 포커스 시 `focus-visible` 링을 표시한다.

### 2.1 Closed (닫힘) — 기본 상태

파일/폴더 이름, 메타, 아이콘, 타입 배지를 표시한다. 콘텐츠 미리보기는 표시하지 않는다.

```
┌─────────────────────────────────────┐
│ [📁]  01_skill_claude               │  ← 이름 (Primary)
│ 폴더 · 12개 항목 · 2026-11-20       │  ← 메타 (Secondary)
│ [폴더]                              │  ← 타입 배지 (Tertiary)
│                                     │
│     [★]   [⋮]                       │  ← 액션 (Quaternary, 호버 시 표시)
└─────────────────────────────────────┘
```

- `.gf-front`는 `opacity: 1` (기본). 이름과 메타를 항상 보여준다.
- `.gf-back`은 닫힘 상태에서는 비움 또는 자리 비움(placeholder)으로 둔다.
- 폴더 아이콘(📁) 또는 파일 아이콘(📄)을 좌측에 배치.

### 2.2 Open (열림) — 뷰어 오버레이

문서 클릭 시 전체 화면/오버레이 뷰어에서 마크다운 콘텐츠를 표시한다.

```
┌─────────────────────────────────────┐
│ 01_skill_claude.md  [✕] [📋] [🌙]   │  ← 뷰어 헤더
├─────────────────────────────────────┤
│                                     │
│   # 제목                            │  ← 콘텐츠 미리보기/본문
│                                     │
│   본문 내용이 여기에 렌더링됩니다.   │
│                                     │
│   ── 목차 사이드바 ──                │
└─────────────────────────────────────┘
```

- 폴더 열기: 그리드가 해당 폴더 내용으로 교체되며 브레드crumb가 업데이트된다.
- 문서 열기: 뷰어 오버레이가 표시되고 `Escape` 또는 닫기 버튼으로 종료.
- `aria-hidden` 토글과 포커스 트랩을 적용.

### 2.3 Hover (호버) — 빠른 작업 표시

마우스 카드 진입 시 빠르게 실행할 수 있는 액션 버튼을 표시한다.

```
┌─────────────────────────────────────┐
│ [📄]  읽기_노트.md                  │
│ 2.4 KB · 2026-11-21                 │
│ [파일]                              │
│                                     │
│   [✏️ 이름변경] [🗑️ 삭제] [📥 다운로드]│  ← 빠른 작업 (퀵 액션)
└─────────────────────────────────────┘
```

- 호버 시 카드 그림자가 깊어지고 테두리 색상이 accent로 변함(`--shadow-deep`, `--color-border-hover`).
- 퀵 액션 버튼은 호버 시에만 불투명도 `0 → 1`로 나타남(접근성을 위해 포커스 시에도 표시).
- 터치 장치에서는 롱프레스 또는 카드 내 "더보기" 버튼으로 대체.

### 2.4 Selected (선택) — 선택 링

Ctrl+Click 또는 Shift+Click으로 다중 선택 시 선택 링을 표시한다.

```
┌─────────────────────────────────────┐
│ ◌ [📄]  선택_문서.md                │  ← 선택 링 (외곽 2px accent)
│ 1.2 KB · 2026-11-21                 │
│ [파일]                              │
└─────────────────────────────────────┘
```

- 선택 링: `2px solid var(--color-focus)`, `outline-offset: 2px`.
- 선택된 카드 배경은 `--color-surface-elev`로 미세하게 차별화.
- 하단 툴바(또는 컨텍스트 메뉴)에서 선택 항목에 대한 일괄 액션(삭제, 다운로드, 이동 등)을 제공.
- `aria-checked="true"`로 선택 상태를 노출.

## 3. 시각적 계층 구조 (Visual Hierarchy)

카드 내부 정보는 다음 네 단계로 우선순위를 부여한다.

| 우선순위 | 요소 | 시각적 처리 | 예 |
|----------|------|-------------|-----|
| 1 (Primary) | 파일/폴더 이름 | 가장 큰 폰트, 텍스트 primary 색상, 볼드 | `01_skill_claude` |
| 2 (Secondary) | 크기/수정일 | 작은 폰트, 텍스트 secondary 색상 | `2.4 KB · 2026-11-21` |
| 3 (Tertiary) | 타입 배지 | 캡션 크기, 배경 칩, 둥근 모서리 | `[폴더]` `[.md]` |
| 4 (Quaternary) | 액션 (퀵 액션) | 아이콘 버튼, 호버/포커스 시 표시 | `[✏️] [🗑️] [📥]` |

### 3.1 카드 시각 사양 (디자인 시스템 적용)

| 속성 | 값 | 비고 |
|------|-----|------|
| 패딩 | `16px` (`--space-m`) | 카드 내부 콘텐츠 여백 |
| 둥근 모서리 | `--radius-md` (8px) | 기본 카드 |
| 테두리 | `1px solid var(--color-border)` | 호버 시 `--color-border-hover` |
| 배경 | `var(--color-surface)` | -- |
| 그림자 | `--shadow-elevated` | 호버/선택 시 `--shadow-deep` |
| 최소 크기 | `44px × 44px` 상호작용 영역 | 접근성 필수 |
| 타이포그래피 | 이름 `.text-h3`, 메타 `.text-caption`, 배지 `.text-overline` | 모듈러 스케일 준수 |

## 4. 상호작용 모델 (Interaction Model)

| 상호작용 | 동작 | 비고 |
|----------|------|------|
| 클릭 (폴더) | 해당 폴더 문서 목록 뷰로 이동 | 브레드crumb, URL 상태 동기화 |
| 클릭 (문서) | 뷰어 오버레이에서 문서 내용 표시 | `Escape`로 닫기 |
| Enter / Space | 포커스된 카드 활성화 (클릭과 동일) | 키보드 접근성 |
| 호버 | 퀵 액션 표시, 카드 강조 | 터치 시 롱프레스 대체 |
| Ctrl+Click | 다중 선택 토글 | 선택 링 표시 |
| Shift+Click | 범위 선택 | 첫 선택 → 마지막 선택 사이 범위 |
| 우클릭 | 컨텍스트 메뉴 표시 | 이름 변경, 삭제, 복제, 다운로드 |
| ? 키 | 키보드 단축키 힌트 오버레이 표시 | 섹션 5.11 |
| 드래그 앤 드롭 | 폴더/문서 이동, 재정렬 | 섹션 5.6 |

### 4.1 컨텍스트 메뉴 (우클릭)

```
┌─────────────────┐
│ 📂 폴더 열기    │
│ ✏️ 이름 변경    │
│ 📋 복제        │
│ 📥 다운로드    │
│ ─────────────── │
│ 🗑️ 삭제        │  ← 오류/주의 색상
└─────────────────┘
```

- `contextmenu` 이벤트 기본 동작 방지, 커스텀 메뉴 렌더링.
- 메뉴는 포인터 위치에 표시되며 뷰포트 밖 시 반대 방향으로 플립.
- Escape 키 또는 외부 클릭 시 메뉴 닫힘.

## 5. 편의 기능 UX (Convenience Features UX)

### 5.1 브레드crumb (Breadcrumb)

- **클릭 가능 세그먼트**: 각 경로 세그먼트는 버튼 역할(`role="button"`)으로 클릭 시 해당 경로 이동.
- **현재 경로 표시**: 마지막 세그먼트는 `aria-current="page"`로 현재 위치 표시, 링크 아님.
- **검색 모드**: "검색 결과" 텍스트만 표시, 클릭不可.

```
[홈] > [open_router] > [doc] > [01_skill_claude]
      ↑클릭 가능      ↑클릭 가능   ↑현재 (링크 아님)
```

### 5.2 검색 (Search)

- **디바운스**: 입력 후 300ms 정지 시 검색 요청(기존 구현 유지, `searchTimer`).
- **인라인 드롭다운 결과**: 입력 시 드롭다운에 최대 10개 결과 미리 표시, 엔터 또는 항목 클릭 시 전체 검색 페이지 이동.
- **키보드 내비게이션**: ↑↓로 드롭다운 항목 이동, Enter로 선택, Esc로 드롭다운 닫힘.
- `aria-live="polite"`로 검색 상태 알림(로드 중, 결과 개수, 오류).

### 5.3 최근 문서 (Recent Docs)

- **자동 채워짐**: 문서 뷰어에서 열면 자동으로 최근 문서 목록에 추가.
- **최대 10개**: 10개 초과 시 가장 오래된 항목부터 제거(FIFO).
- **제거 가능**: 각 항목에 삭제 버튼(`×`)으로 목록에서 제거 가능.
- 사이드바 또는 홈 대시보드에 "최근 문서" 섹션으로 표시.

### 5.4 호버 미리보기 (Preview on Hover)

- **첫 200자**: 문서 카드 호버 시 문서 내용의 첫 200자를 미리보기 텍스트로 표시.
- **마우스 리브 시 페이드아웃**: 마우스가 카드를 떠나면 200ms ease로 미리보기가 페이드아웃.
- `prefers-reduced-motion` 시 즉시 사라짐.

### 5.5 드래그 앤 드롭 (Drag & Drop)

- **시각 피드백**: 드래그 시작 시 원본 카드는 반투명(`opacity: 0.5`), 드래그 이미지 표시.
- **드롭 존**: 폴더 카드 위에서 드래그 시 해당 폴더 하이라이트(테두리 accent, 배경 미세 변화).
- **재정렬 애니메이션**: 그리드 내 카드 위치 교체 시 `transform` 기반 슬라이드 애니메이션(`prefers-reduced-motion` 제외).
- 키보드 대체: 선택된 항목을 컨텍스트 메뉴 또는 단축키로 이동 대상으로 지정 가능.

### 5.6 그리드/리스트 토글 (Grid/List)

- **토글 버튼**: 툴바에 그리드 아이콘/리스트 아이콘 버튼, 현재 모드 표시(`aria-pressed`).
- **카드 밀도 차이**:
  - 그리드: 카드당 패딩 16px, 이미지/아이콘 포함, 2~4열(반응형).
  - 리스트: 행당 패딩 8px 16px, 더 컴팩트한 메타 정보, 가로 전체 너비.

### 5.7 즐겨찾기 (Favorites)

- **별표 아이콘**: 카드 우상단 또는 리스트 행에 ☆/★ 아이콘, 클릭 시 토글.
- **즐겨찾기 필터**: 툴바 또는 사이드바에 "즐겨찾기만 보기" 필터, 활성 시 별표 표시.
- `aria-pressed`로 선택 상태 노출, 로컬 스토리지에 영구 저장.

### 5.8 빠른 작업 (Quick Actions)

| 작업 | 동작 | UI |
|------|------|-----|
| 이름 변경 | 인라인 편집 | 카드 내 이름 영역 클릭 시 입력 필드로 대체, Enter 저장 / Esc 취소 |
| 삭제 | 확인 대화상자 | 모달로 "정말로 삭제하시겠습니까?" 확인, 확인 시 삭제 |
| 복제 | 문서/폴더 복제 | "이름_복사본" 명명, 새 카드 생성 |
| 다운로드 | 파일 다운로드 | 브라우저 다운로드 대화상자, 폴더는 ZIP 압축 다운로드 |

### 5.9 태그 (Tags)

- **색상 코드**: 태그별 배경 색상(예: 빨강, 파랑, 초록, 보라), 텍스트는 대비 확보.
- **필터 가능**: 태그 클릭 시 해당 태그가 붙은 문서만 표시, 다중 태그 선택 시 AND/OR 조건 선택 가능.
- 태그는 문서 메타데이터에 저장, 사이드바에 태그 목록 표시.

### 5.10 내보내기 (Export)

- **CSV/JSON 다운로드 버튼**: 툴바에 "내보내기" 드롭다운, 현재 표시 중인 문서 목록(또는 전체)을 CSV/JSON으로 다운로드.
- 포함 항목: 이름, 경로, 타입, 크기, 수정일, 태그, 즐겨찾기 여부.

### 5.11 키보드 단축키 (Keyboard Shortcuts)

- **? 키**: 시각적 힌트 오버레이 표시. 전체 화면 오버레이에 단축키 목록 테이블 표시, Esc 또는 ?로 닫힘.
- 주요 단축키 예시:

| 단축키 | 동작 |
|--------|------|
| `Ctrl + Click` | 다중 선택 토글 |
| `Shift + Click` | 범위 선택 |
| `↑ ↓ ← →` | 카드 간 포커스 이동 |
| `Enter / Space` | 선택 카드 열기 |
| `Ctrl + A` | 전체 선택 |
| `Del` | 선택 항목 삭제 (확인 대화상자) |
| `F2` | 선택 항목 이름 변경 (인라인 편집) |
| `?` | 단축키 힌트 오버레이 |
| `Esc` | 모달/드롭다운/뷰어 닫기 |
| `Ctrl + F` | 검색 입력 포커스 |

### 5.12 테마 토글 (Theme Toggle)

- **태양/달 아이콘**: 툴바 또는 사이드바에 테마 전환 버튼, `aria-label`로 현재 테마 표시.
- **선호도 지속**: 선택된 테마(라이트/다크)를 `localStorage`에 저장, 페이지 로드 시 복원.
- 시스템 선호도(`prefers-color-scheme`) 초기값으로 사용, 사용자 선택이 우선.

### 5.13 정렬 (Sort)

- **정렬 기준**: 이름, 수정일, 크기.
- **방향**: 오름차순/내림차순 토글, 정렬 표시기(▲/▼)를 헤더에 표시.
- `aria-sort="ascending/descending"`로 정렬 상태 노출.

### 5.14 페이지네이션 (Pagination)

- **Prev/Next + 페이지 번호**: "이전" / "다음" 버튼과 중간 페이지 숫자, 현재 페이지 강조.
- **페이지 크기 선택기**: 10 / 20 / 50 / 100 항목 per page 선택.
- 전체 항목 수가 적은 경우(예: 20개 이하) 페이지네이션 숨김.

### 5.15 실행 취소/재실행 (Undo/Redo)

- **토스트 알림 + 액션 버튼**: 삭제/이동/이름 변경 후 하단 토스트에 "실행 취소" 버튼 표시(5초 유지).
- 클릭 시 작업 원상복구, 재실행은 별도 히스토리 스택으로 관리(선택적).
- `aria-live="assertive"`로 토스트 내용 알림.
