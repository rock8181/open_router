### 1.1 목적

### 1.2 배경 및 문제 현상

현재 문서 카드 컴포넌트 (`public/app.js`, `public/app.v2.js`, `public/style.css`) 는 아래 구조로 동작한다.

- `.gf-stage`: 카드 전체 영역 (position: relative)
- `.gf-back`: 카드 뒷면 (z-index: 1, 기본 가시), 현재 **빈 div** (`<div class="gf-back"></div>`)
- `.gf-front`: 카드 앞면 (z-index: 2, 기본 `opacity: 0`), 파일/폴더명, 메타, 버튼 포함
- `.gf-root.open .gf-front`: 카드 열림 상태에서만 `opacity: 1`

**버그**: `.gf-front` 가 기본적으로 `opacity: 0` 이므로, 카드를 열지 않으면 파일/폴더명이 전혀 보이지 않는다. `.gf-back` 은 비어 있어 닫힌 상태에서 보여줄 콘텐츠가 없다. 사용자는 모든 카드를 하나씩 클릭(열기)해야만 어떤 문서인지 확인할 수 있어 UX 가 심각하게 저하된다.

## 2. 버그 수정 요구사항 (P0)

### 2.1 Bug-01: 닫힌 문서 카드에서 파일/폴더명 가시성 확보

**우선순위**: P0 (치명적, 차단 이슈)

**문제**: `.gf-front { opacity: 0; }` 기본값으로 인해 닫힌 카드에서 파일/폴더명이 숨겨진다. `.gf-back` 은 빈 콘텐츠를 가진다.

**요구사항**:
1. 카드가 **닫힌 상태 (`.gf-root` 미열림)** 에서도 파일명/폴더명을 명확히 표시해야 한다.
2. `.gf-back` 에 파일/폴더명, 타입 배지, 메타 정보(크기/수정일/문서 수)를 렌더링하여 기본 가시 영역으로 활용한다.
3. `.gf-front` 는 카드를 열었을 때(호버 또는 클릭) 추가 상세 정보를 보여주는 오버레이로 동작하도록 조정한다.
4. 카드 닫힘/열림 전환 시 접근성 속성(`aria-expanded`, `aria-label`) 을 정확히 갱신해야 한다.
5. 모션 축소 선호(`prefers-reduced-motion`) 사용자도 콘텐츠를 읽을 수 있어야 한다.

**수용 기준 (Acceptance Criteria)**:
- [ ] 카드를 클릭하지 않고 닫힌 상태에서 파일명/폴더명이 텍스트로 보인다.
- [ ] `.gf-back` 이 비어 있지 않으며, 최소 파일명/폴더명과 타입 배지를 포함한다.
- [ ] `.gf-front` 의 `opacity: 0` 기본값이 닫힌 상태에서 콘텐츠 가시성을 해치지 않는다 (필요시 콘텐츠를 `.gf-back` 으로 이동).
- [ ] 카드 호버 또는 클릭 시 추가 상세 정보(스니펫, 미리보기 등)가 표시된다.
- [ ] 키보드 Tab 포커스 시 카드 이름이 접근성 트리로 노출된다.
- [ ] 다크/라이트 모드 모두에서 텍스트 대비가 WCAG AA (4.5:1) 를 만족한다.

**관련 파일**:
- `public/style.css` (`.gf-back`, `.gf-front`, `.gf-root.open .gf-front`)
- `public/app.js` (함수 `createCard` ~225-279)
- `public/app.v2.js` (동일 구조)

## 3. 신규 편의 기능 요구사항 (P1)

아래 기능들은 버그 수정 완료 후 단계적으로 구현한다. 각 기능은 수용 기준을 포함한다.

### 3.1 FEAT-01: 브레드크럼 내비게이션

**설명**: 현재 폴더 경로를 클릭 가능한 세그먼트로 표시해 상위 폴더로 빠르게 이동할 수 있다.

**수용 기준**:
- [ ] 경로의 각 세그먼트가 클릭 가능한 링크로 렌더링된다.
- [ ] 클릭 시 해당 상위 폴더의 문서 목록 뷰로 이동한다.
- [ ] 마지막 세그먼트(현재 폴더)는 비활성 상태(텍스트 only)로 표시된다.
- [ ] 경로 구분자는 `/` 또는 chevron 아이콘을 사용한다.
- [ ] 루트 경로에서는 브레드크럼을 숨기거나 "홈" 하나만 표시한다.
- [ ] 모바일에서는 경로가 길 경우 오른쪽으로 스크롤되거나 축약된다.

### 3.2 FEAT-02: 빠른 검색 (디바운스 + 인라인 결과)

**설명**: 문서명/내용으로 실시간 검색하며, 입력 중단 후 300ms 디바운스로 검색을 실행하고 결과를 카드 위에 인라인 표시한다.

**수용 기준**:
- [ ] 검색 입력 필드가 상단 고정 또는 사이드바에 위치한다.
- [ ] 입력 후 300ms 정지 시 검색 API 호출 (디바운스).
- [ ] 검색 결과는 카드 그리드 위에 인라인 드롭다운 또는 필터된 그리드로 표시된다.
- [ ] 결과 항목에 일치 키워드가 하이라이팅된다.
- [ ] 검색어 삭제 시 모든 카드가 복원된다.
- [ ] 검색 결과가 없으면 "검색 결과가 없습니다" 메시지가 표시된다.
- [ ] `Esc` 키로 검색을 취소하고 기본 뷰로 돌아간다.

### 3.3 FEAT-03: 최근 문서 목록 (최근 10개 접근)

**설명**: 사용자가 최근에 열어본 문서 최대 10개를 목록으로 제공해 빠르게 재진입할 수 한다.

**수용 기준**:
- [ ] 문서 뷰어에서 문서를 열 때마다 최근 문서 목록에 추가된다.
- [ ] 최대 10개까지 저장하며, 초과 시 가장 오래된 항목부터 제거된다(FIFO).
- [ ] 중복 접근 시 기존 항목은 갱신되어 최상위로 이동한다.
- [ ] 사이드바 또는 대시보드에 "최근 문서" 섹션으로 표시된다.
- [ ] 각 항목에 문서명, 경로, 최종 접근 시간이 표시된다.
- [ ] 항목 클릭 시 해당 문서 뷰어가 열린다.
- [ ] 목록 비우기(전체 삭제) 기능이 제공된다.

### 3.4 FEAT-04: 문서 미리보기 (호버, 첫 200자)

**설명**: 카드에 마우스를 올리면 문서의 첫 200자 미리보기를 표시한다.

**수동 기준**:
- [ ] 카드 호버 시 미리보기 오버레이가 나타난다.
- [ ] 미리보기 내용은 문서의 첫 200자(공백 포함)를 보여준다.
- [ ] 200자 초과 시 "..." 로 생략된다.
- [ ] 이미지/이진 파일은 텍스트 미리보기 대신 파일 아이콘과 유형 안내를 표시한다.
- [ ] 호버 해제 시 200ms 내에 미리보기가 사라진다.
- [ ] 터치 장치에서는 롱프레스 또는 더블탭으로 미리보기를 토글한다.

### 3.5 FEAT-05: 카드 드래그 앤 드롭 재정렬

**설명**: 사용자가 카드를 마우스로 드래그해 순서를 변경할 수 있다.

**수용 기준**:
- [ ] 카드를 드래그해 그리드 내 다른 위치로 이동할 수 있다.
- [ ] 드래그 중 이동 대상 위치에 시각적 플레이스홀더(삽입 표시)가 나타난다.
- [ ] 드랍 시 카드 순서가 영구히 변경되고 서버/로컬 스토리지에 반영된다.
- [ ] 폴더 간 이동은 지원하지 않으며, 동일한 폴더 내 카드만 재정렬 가능하다.
- [ ] 키보드 전용 사용자를 위해 정렬 순서 변경 단축키(예: Ctrl+Shift+↑/↓)를 제공한다.
- [ ] `prefers-reduced-motion` 시 애니메이션을 최소화한다.

### 3.6 FEAT-06: 그리드/리스트 뷰 토글

**설명**: 문서 카드를 그리드(카드) 형태와 리스트(테이블) 형태로 전환할 수 있다.

**수용 기준**:
- [ ] 툴바에 그리드 아이콘과 리스트 아이콘 버튼이 있다.
- [ ] 클릭 시 뷰 모드가 즉시 전환된다.
- [ ] 그리드 모드: 카드 형태, 썸네일/아이콘 + 제목 + 메타.
- [ ] 리스트 모드: 행 형태, 파일명/수정일/크기/유형 열 포함.
- [ ] 뷰 모드 선택은 로컬 스토리지에 저장되어 페이지 재방문 시 유지된다.
- [ ] 두 모드 모두 접근성(키보드 포커스, 스크린 리더)을 만족한다.

### 3.7 FEAT-07: 문서 즐겨찾기(스타) 시스템

**설명**: 문서를 별표 표시로 즐겨찾기해 따로 모아볼 수 있다.

**수용 기준**:
- [ ] 카드/목록 항목에 별(★/☆) 버튼이 있다.
- [ ] 클릭 시 즐겨찾기 상태가 토글되고 서버/로컬 스토리지에 저장된다.
- [ ] 즐겨찾기된 문서는 별이 채워진 상태(활성 색상)로 표시된다.
- [ ] 사이드바 또는 필터에 "즐겨찾기만 보기" 옵션이 있다.
- [ ] 즐겨찾기 문서 목록은 별도 섹션으로 모아볼 수 있다.
- [ ] 상태 변경 시 토스트 알림이 표시된다.

### 3.8 FEAT-08: 빠른 작업 툴바 (이름 변경, 삭제, 복제, 다운로드)

**설명**: 카드/목록 항목에서 즉시 실행할 수 있는 파일 작업 버튼을 제공한다.

**수용 기준**:
- [ ] 각 카드/행에 "더보기(···)" 버튼 또는 하단 툴바가 있다.
- [ ] 작업 메뉴에 이름 변경, 삭제, 복제, 다운로드가 포함된다.
- [ ] 이름 변경: 인라인 입력 필드로 파일명 수정, 저장/취소 버튼.
- [ ] 삭제: 확인 다이얼로그 표시 후 삭제 실행, 취소 가능.
- [ ] 복제: "복사본_파일명" 으로 새 파일 생성.
- [ ] 다운로드: 파일을 로컬로 다운로드 (브라우저 다운로드 API).
- [ ] 작업 결과는 토스트 알림으로 피드백한다.
- [ ] 삭제/복제 시 Undo 버튼이 5초간 표시된다 (FEAT-15 와 연계).

### 3.9 FEAT-09: 문서 태그/카테고리

**설명**: 문서에 태그를 지정해 분류하고 필터링할 수 있다.

**수용 기준**:
- [ ] 문서에 하나 이상의 태그를 붙일 수 있다 (예: #공부, #프로젝트, #메모).
- [ ] 태그는 색상 배지 형태로 카드에 표시된다.
- [ ] 태그 입력 시 기존 태그 자동완성이 제안된다.
- [ ] 태그별 필터 버튼이 사이드바 또는 상단에 있다.
- [ ] 태그 클릭 시 해당 태그가 붙은 문서만 표시된다.
- [ ] 태그 관리(추가/이름 변경/삭제) 기능이 제공된다.

### 3.10 FEAT-10: 문서 목록 내보내기 (CSV/JSON)

**설명**: 현재 폴더의 문서 목록을 CSV 또는 JSON 파일로 내보낼 수 있다.

**수용 기준**:
- [ ] "내보내기" 버튼이 툴바에 있다.
- [ ] CSV: 파일명, 유형, 크기, 수정일, 경로 열 포함.
- [ ] JSON: 동일한 필드를 구조화된 객체 배열로 포함.
- [ ] 내보내기 시 브라우저 다운로드 다이얼로그가 뜬다.
- [ ] 파일명은 `documents_YYYYMMDD.csv` 또는 `.json` 형태다.
- [ ] 선택된 문서만 내보내기 옵션도 제공한다 (선택 시).

### 3.11 FEAT-11: 키보드 단축키

**설명**: 마우스 없이 키보드로 주요 기능을 빠르게 사용할 수 있다.

**수용 기준**:
| 단축키 | 기능 |
|--------|------|
| `Ctrl + F` | 검색 입력 필드 포커스 |
| `Ctrl + N` | 새 폴더 만들기 |
| `Ctrl + O` | 선택된 문서/폴더 열기 |
| `Esc` | 검색 취소, 모달 닫기, 카드 닫기 |
| `Ctrl + S` | 즐겨찾기 토글 (선택 항목) |
| `Ctrl + D` | 삭제 (선택 항목, 확인 다이얼로그) |
| `↑ / ↓` | 카드/목록 항목 이동 |
| `Enter` | 포커스된 항목 열기 |

- [ ] 단축키는 전역 리스너로 동작하며, 입력 필드 포커스 시에는 제외된다.
- [ ] 단축키 목록은 `?` 키 또는 도움말 버튼으로 확인할 수 있다.
- [ ] 맥 사용자는 `Cmd` 키로 대체 동작한다.

### 3.12 FEAT-12: 다크/라이트 모드 토글

**설명**: 화면 테마를 다크 모드와 라이트 모드로 전환할 수 있다.

**수용 기준**:
- [ ] 테마 토글 버튼이 상단 또는 사이드바에 있다.
- [ ] 기본값은 다크 모드 (02_frontend-ui.md 준수).
- [ ] 클릭 시 즉시 테마가 전환되며 CSS 변수(`--color-*`) 가 갱신된다.
- [ ] 선택된 테마는 로컬 스토리지에 저장되어 재방문 시 유지된다.
- [ ] 시스템 테마 선호도(`prefers-color-scheme`) 를 최초 방문 시 반영한다.
- [ ] 모든 컴포넌트(카드, 모달, 툴바, 뷰어)가 테마 변경에 반응한다.

### 3.13 FEAT-13: 문서 크기/날짜 정렬

**설명**: 문서 목록을 이름, 크기, 수정일 기준으로 정렬할 수 있다.

**수용 기준**:
- [ ] 정렬 기준 선택 드롭다운이 툴바에 있다 (이름, 크기, 수정일).
- [ ] 오름차순/내림차순 토글이 있다.
- [ ] 폴더는 항상 상단에 고정 (정렬 기준과 무관).
- [ ] 정렬 상태는 로컬 스토리지에 저장된다.
- [ ] 리스트 뷰에서 열 헤더 클릭으로도 정렬 변경 가능하다.
- [ ] 정렬 아이콘(↑/↓) 이 현재 상태를 시각적으로 표시한다.

### 3.14 FEAT-14: 대용량 폴더 페이징

**설명**: 문서 수가 많은 폴더에서 페이지 단위로 분할 표시한다.

**수용 기준**:
- [ ] 기본 페이지 크기는 20개 (옵션: 20/50/100).
- [ ] 페이지 네이션 컨트롤(이전/다음, 페이지 번호)이 하단에 있다.
- [ ] 현재 페이지와 전체 페이지 수가 표시된다 (예: "1 / 5").
- [ ] 검색/필터 적용 시 페이징이 재계산된다.
- [ ] URL 쿼리 파라미터(`?page=2`) 로 페이지 상태를 공유할 수 있다.
- [ ] 무한 스크롤 옵션도 제공할 수 있다 (선택).

### 3.15 FEAT-15: 파일 연산 실행취소/다시실행 (Undo/Redo)

**설명**: 삭제, 복제, 이름 변경 등 파일 작업을 취소하거나 다시 실행할 수 있다.

**수용 기준**:
- [ ] 삭제/복제/이름 변경 작업 후 토스트에 "실행취소" 버튼이 5초 표시된다.
- [ ] 실행취소 클릭 시 작업 직전 상태로 복구된다.
- [ ] `Ctrl + Z` 로 실행취소, `Ctrl + Shift + Z`(또는 `Ctrl + Y`) 로 다시실행.
- [ ] 히스토리는 최대 20 스텝까지 저장된다.
- [ ] 실행취소 불가능한 상태(예: 서버 삭제 완료 후) 는 버튼을 비활성화한다.
