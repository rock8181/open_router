## 4. 리스크 관리

| 리스크 | 영향도 | 발생 확률 | 완화 전략 |
|--------|--------|----------|----------|
| 빈 카드 버그 재발 | 높음 | 중 | 수정 전 철저한 원인 분석, 회귀 테스트 추가 |
| 일정 지연 | 중 | 중 | 일일 스탠드업으로 진행 상황 모니터링, 버퍼 일정 확보 |
| 디자인 시스템 지연 | 중 | 중 | 재사용 가능한 컴포넌트 우선 구현, 점진적 적용 |
| 접근성 미준수 | 중 | 중 | 개발 초기부터 접근성 가이드라인 적용, WCAG 2.1 AA 기준 준수 |
| 배포 실패 | 높음 | 낮 | 스테이징 환경 사전 검증, 롤백 계획 수립 |
| 인력 리소스 부족 | 중 | 낮 | 그룹 간 크로스 트레이닝, 우선순위 기반 업무 재배분 |
