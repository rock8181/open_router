# OpenRouter 학습 문서 뷰어 사용자 가이드

OpenRouter 학습 문서 뷰어를 사용하는 방법을 안내합니다. 폴더 탐색, 문서 열기, 검색, 즐겨찾기, 내보내기, 테마 전환 등 주요 기능을 포함합니다.

## 1. 시작하기

1. 서버를 실행합니다 (`npm start`).
2. 브라우저에서 `http://localhost:3000`에 접속합니다.
3. 사이드바에서 문서 루트를 선택합니다.

| 루트 | 설명 |
|------|------|
| `open_router/doc` | OpenRouter 관련 문서 |
| `study/01_skill_claude` | 스터디 문서 (Claude 기술 등) |

---

## 2. 폴더 탐색

### 폴더 이동

1. 사이드바에서 원하는 루트를 클릭합니다.
2. 문서 그리드에서 폴더 카드를 클릭(또는 Enter)하면 해당 폴더로 이동합니다.
3. 상단의 빵부스러기 내비게이션(breadcrumb)에서 현재 경로를 확인할 수 있습니다.

### 뒤로 돌아가기

- 브라우저의 "뒤로 가기" 버튼을 사용하면 이전에 본 폴더로 돌아갑니다.
- 새 탭/창을 열지 않고 SPA(단일 페이지 애플리케이션)처럼 동작합니다.

### 새로고침

- 도구 모음의 "새로고침" 버튼을 클릭하면 현재 폴더의 문서 목록을 다시 불러옵니다.

---

## 3. 문서 열기

1. 문서 그리드에서 `.md` 파일 카드를 클릭합니다.
2. 문서 뷰어 오버레이가 열리며, 문서 제목과 원본 마크다운 내용이 표시됩니다.
3. 뷰어 상단의 "복사" 버튼을 누르면 문서 전체 내용을 클립보드에 복사합니다.
4. "닫기" 버튼이나 `Esc` 키, 오버레이 외부 영역을 클릭하면 뷰어가 닫힙니다.

### 뷰어 내 유의사항

- 문서 내용은 서버에서 마크다운 → HTML로 변환된 상태로 제공되지만, 현재 뷰어는 원본 텍스트를 표시합니다.
- 매우 긴 문서는 스크롤로 읽을 수 있습니다.

---

## 4. 문서 검색

### 검색 실행

1. 사이드바의 검색 입력창에 키워드를 입력합니다.
2. "검색" 버튼을 클릭하거나 Enter를 누릅니다.
3. 입력 시 300ms 디바운스 후 자동 검색이 실행됩니다(입력 중단 후).

### 검색 결과

- 문서 제목과 본문 내용에서 키워드가 포함된 모든 문서가 검색됩니다.
- 대소문자를 구분하지 않습니다.
- 각 결과에는 관련성 점수와 검색어 주변 스니펫(문맥)이 표시됩니다.
- 최대 20개의 결과까지 표시됩니다.
- 검색 결과 그리드에서 문서를 클릭하면 일반 문서와 동일하게 뷰어로 열 수 있습니다.

### 검색 취소

- 검색 입력창을 비우면 일반 문서 목록으로 돌아옵니다.

---

## 5. 키보드 단축키

모든 기능은 마우스 없이 키보드만으로 조작할 수 있습니다.

| 단축키 | 동작 | 사용 위치 |
|--------|------|-----------|
| `Tab` | 다음 상호작용 요소로 포커스 이동 | 전체 페이지 |
| `Shift + Tab` | 이전 상호작용 요소로 포커스 이동 | 전체 페이지 |
| `Enter` | 포커스된 카드 활성화 (폴더 열기 / 문서 열기) | 문서 그리드 |
| `Space` | 포커스된 카드 활성화 | 문서 그리드 |
| `Esc` | 문서 뷰어 오버레이 닫기 | 뷰어 열림 시 |
| `Enter` / `Space` | 버튼 활성화 | 도구 모음, 뷰어 버튼 |

### 포커스 순서

1. 사이드바 루트 버튼
2. 검색 입력창 / 검색 버튼
3. 도구 모음 버튼 (새로고침, 추가, 더보기)
4. 문서 그리드 카드 (왼쪽→오른쪽, 위→아래)
5. 뷰어 오버레이 (닫기 버튼 → 복사 버튼)

## 6. 문서 목록 내보내기(Export)

현재 뷰어는 서버 측에 문서 생성/수정/삭제 엔드포인트를 노출하지 않으므로, "내보내기"는 다음과 같은 방식으로 수행합니다.

### 수동 내보내기

1. 내보내고 싶은 폴더로 이동합니다.
2. 브라우저 주소 표시줄의 URL을 복사합니다(`?root=`와 `?dir=` 파라미터 포함).
3. 해당 URL을 그대로 공유하거나 북마크하면, 다른 사용자가 동일한 폴더를 열 수 있습니다.

### 문서 내용 복사

1. 문서 뷰어에서 문서를 엽니다.
2. "복사" 버튼을 클릭합니다.
3. 클립보드에 원본 마크다운 내용이 복사되며, 외부 에디터나 노션 등에 붙여넣어 저장할 수 있습니다.

> 참고: 프로그램matic 내보내기(파일 다운로드, ZIP 압축 등)는 향후 버전에서 추가될 예정입니다.

## 7. 즐겨찾기(Favorite)

현재 뷰어는 서버 측에 즐겨찾기 저장 엔드포인트를 제공하지 않습니다. 즐겨찾기 기능은 다음과 같이 대체 사용할 수 있습니다.

### 브라우저 북마크 활용

1. 자주 찾는 폴더나 문서를 뷰어로 엽니다.
2. 브라우저의 북마크 추가(`Ctrl + D` / `Cmd + D`)를 눌러 저장합니다.
3. URL에 `root`와 `dir`(또는 `file`) 파라미터가 포함되어 있으므로, 북마크에서 바로 해당 경로를 열 수 있습니다.

### 문서 복사로 외부 저장

1. 문서 뷰어에서 "복사" 버튼을 누릅니다.
2. 노션, 옵시디언, 마크다운 에디터 등 외부 도구에 붙여넣어 개인 문서 저장소에 보관합니다.

> 서버 측 즐겨찾기 DB 연동은 로드맵에 포함되어 있습니다.

## 8. 다크/라이트 모드

현재 애플리케이션은 디자인 시스템(`DESIGN_SYSTEM.md`)에 따라 라이트 모드와 다크 모드 토큰을 정의하고 있습니다.

### 테마 전환 방법

CSS 변수 `data-tone` 속성으로 테마를 제어합니다.

```html
<!-- 라이트 모드 (기본) -->
<html data-tone="light">

<!-- 다크 모드 -->
<html data-tone="dark">
```

브라우저 개발자 도구에서 `<html>` 태그의 `data-tone` 속성을 `light` ↔ `dark`로 변경하면 테마가 전환됩니다.

> UI 상에 테마 전환 토글 버튼은 아직 구현되지 않았습니다. 향후 릴리스에서 사이드바 또는 헤더에 테마 스위치를 추가할 예정입니다.

### 테마별 색상 요약

| 요소 | 라이트 모드 | 다크 모드 |
|------|-------------|-----------|
| 배경 | 밝은 회청색 (`hsl(210, 20%, 97%)`) | 짙은 남청색 (`hsl(220, 30%, 8%)`) |
| 표면(카드, 사이드바) | 흰색 | 짙은 회청색 (`hsl(220, 25%, 15%)`) |
| 기본 텍스트 | 짙은 남청색 | 밝은 회색 (`hsl(200, 15%, 95%)`) |
| 액센트(브랜드) | 시안 (`hsl(190, 85%, 45%)`) | 밝은 시안 (`hsl(190, 90%, 55%)`) |

## 9. 문제 해결

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| 문서 목록이 표시되지 않음 | 서버가 실행되지 않음 | `npm start`로 서버 재시작 후 페이지 새로고침 |
| "Access denied" 오류 | 허용되지 않은 루트 요청 | `open_router` 또는 `study`만 사용 |
| "File not found" 오류 | 문서 경로가 잘못됨 | 파일이 실제로 존재하는지 확인 |
| 검색 결과가 없음 | 키워드와 일치하는 문서 없음 | 다른 키워드로 재검색 |
| 클립보드 복사 실패 | HTTPS가 아닌 환경 | localhost에서 접속하거나 HTTPS 사용 |
