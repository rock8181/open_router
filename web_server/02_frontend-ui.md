# 프론트엔드 UI 설계 문서

## 1. 개요

본 문서는 문서 탐색 및 뷰어 웹 페이지의 UI/UX 설계를 다룬다. 사용자가 로컬 문서(마크다운 파일)를 폴더 단위로 탐색하고, 원하는 문서를 선택해 뷰어에서 읽으며, 키워드로 문서를 검색할 수 있는 웹 인터페이스를 정의한다.

## 2. 디자인 컨셉

- **다크 테마**: OpenRouter 이미지 스타일과 유사한 어두운 배경을 기반으로 한다. 눈이 편안하고 코드/문서 가독성이 높은 다크 모드를 기본으로 한다.
- **카드형 문서 목록**: 문서를 폴더/그룹 단위로 카드 형태의 그리드에 배치하여 직관적인 탐색을 지원한다.
- **사이드바 내비게이션**: 좌측 고정 사이드바에서 폴더/태그/최근 문서를 이동할 수 있다.
- **마크다운 뷰어**: 선택한 문서를 마크다운 렌더링 영역에서 보여주며, 목차 사이드바, 복사 버튼, 다크/라이트 테마 토글을 제공한다.

## 3. 페이지 구조

### 3.1 메인 대시보드 (`/`)

폴더별 문서 카드 그리드를 보여주는 진입점이다.

- **경로 예시**: `open_router/doc`, `study/01_skill_claude` 그룹화
- 각 폴더를 카드로表示하고, 카드 내부에 문서 수와 대표 파일 목록을 표시
- 카드 클릭 시 해당 폴더의 문서 목록 뷰로 이동

### 3.2 문서 목록 뷰

선택된 폴더 내의 문서들을 테이블 또는 카드 목록으로 나열한다.

- 정렬: 이름, 수정일, 크기 오름차순/내림차순
- 필터: 확장자(.md, .txt 등), 키워드 포함 여부
- 목록 항목: 아이콘, 파일명, 수정일, 크기, 미리보기 스니펫

### 3.3 문서 뷰어

선택한 문서의 내용을 마크다운으로 렌더링해 보여준다.

- 마크다운 렌더링 영역 (marked.js 사용)
- 목차 사이드바 (H1~H6 제목 기반 자동 생성)
- 복사 버튼 (클립보드에 내용 복사)
- 다크/라이트 테마 토글
- 글꼴 크기 조절 (선택)

### 3.4 검색 페이지

전체 문서 인덱스에서 키워드로 문서를 검색한다.

- 검색 바 (자동 포커스, 엔터 검색)
- 결과 목록 (문서명, 일치 스니펫, 경로)
- 검색어 하이라이팅 (결과 및 뷰어에서 강조 표시)

## 4. 컴포넌트

| 컴포넌트 | 설명 |
|----------|------|
| `DocumentCard` | 폴더 또는 단일 문서를 나타내는 카드. 썸네일/아이콘, 제목, 메타정보 포함 |
| `DocumentList` | 문서 목록을 테이블 또는 카드 형태로 렌더링. 정렬/필터 제어 포함 |
| `MarkdownViewer` | 마크다운 텍스트를 HTML로 렌더링해 보여주는 뷰어 영역 |
| `SearchBar` | 검색 입력 필드, 제출 버튼, 최근 검색어/자동완성 |
| `SidebarNav` | 좌측 사이드바 내비게이션. 폴더 트리, 즐겨찾기, 테마 토글 |
| `Toast` | 작업 결과 알림(복사 완료, 오류 등). 하단 구현, 자동 소멸 |

## 5. 기술 스택

- **언어**: Vanilla HTML / CSS / JavaScript (또는 간단한 템플릿 엔진)
- **마크다운 렌더링**: `marked.js` (CDN 사용)
- **아이콘**: Lucide / Heroicons SVG 또는 인라인 SVG
- **스타일**: CSS 변수 기반 다크/라이트 테마, 미디어 쿼리 반응형 디자인
- **반응형**: 모바일에서는 사이드바를 드로어(오버레이)로, 데스크톱에서는 고정 사이드바로 동작

## 6. 사용자 흐름

1. **대시보드 진입** (`/`): 폴더별 문서 카드 그리드 확인
2. **폴더 선택**: `open_router/doc` 또는 `study/01_skill_claude` 카드 클릭
3. **문서 클릭**: 문서 목록 뷰에서 특정 문서 선택
4. **뷰어 열기**: 마크다운 뷰어에서 문서 내용 렌더링, 목차 확인, 복사 등 상호작용
5. **검색**: 검색 바에서 키워드 입력 → 결과 목록 확인 → 문서 클릭 → 뷰어에서 하이라이팅된 내용 확인

## 7. 색상 및 폰트

### 7.1 색상 팔레트

| 역할 | 다크 테마 | 비고 |
|------|-----------|------|
| 배경 (Background) | `#0f172a` | 메인 페이지 배경 |
| 표면 (Surface) | `#1e293b` | 카드, 모달, 사이드바 배경 |
| 강조 (Primary) | `#10b981` | emerald-500, 버튼/링크/액티브 상태 |
| 텍스트 primary | `#f1f5f9` | 본문 텍스트 |
| 텍스트 secondary | `#94a3b8` | 보조 설명 텍스트 |
| 테두리 (Border) | `#334155` | 카드/입력 필드 테두리 |
| 오류 (Error) | `#ef4444` | 오류 메시지, 삭제 액션 |

### 7.2 폰트

- **시스템 폰트 우선**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- 코드 블록: `"Courier New", Courier, monospace`
- 제목: 굵은 웨이트(600~700), 본문: 일반 웨이트(400), 행간 1.6

## 8. 반응형 디자인 가이드

- **브레이크포인트**: 768px (태블릿 이하)
- **데스크톱 (≥768px)**: 좌측 사이드바 고정 + 메인 콘텐츠 영역
- **모바일 (<768px)**: 사이드바는 햄버거 메뉴로 드로어 오버레이, 카드 그리드는 1열
